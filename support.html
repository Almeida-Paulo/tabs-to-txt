Support · Tabs to txt

Product help and technical support for Tabs to txt.

Export tabs

  1. Select tabs in the browser's tab bar, or expand Tab selection in the popup.
  2. Enter a File name.
  3. Select Export TXT.

The exported file preserves tab order and contains one URL per line.

Import tabs

  1. Select Import TXT in the popup.
  2. Select the saved TXT file.
  3. Confirm the number of valid URLs and select Open tabs.

HTTP and HTTPS URLs open in background tabs in the same window. Files must use UTF-8 with one URL per line.

Import and export issues

Tabs without an accessible URL are unavailable for export. Safari website access is managed in the browser's extension settings.

Blank lines are ignored during import. Invalid or unsupported entries are reported. Following a partial import, Open tabs retries only the remaining URLs.
