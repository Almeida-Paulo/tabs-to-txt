Support · Tabs to txt

Save the URLs of the tabs you choose and reopen links from a TXT file whenever you need them.

Save tabs

Select tabs in your browser or use Choose tabs in this window in the popup. Name the file and click Save TXT.

Import tabs

Click Import TXT, select your file, then click Open tabs. Use a UTF-8 TXT file with one HTTP or HTTPS URL per line.
